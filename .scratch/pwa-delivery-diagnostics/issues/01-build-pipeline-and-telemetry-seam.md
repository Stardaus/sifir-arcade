# 01: Build Pipeline, Dependencies & Build Telemetry Seam

Status: `DONE`
Blocked by: None

---

### Description
Install Workbox and configure the build pipeline to generate a content-hashed Service Worker and a compile-time build telemetry endpoint (`version.json`). This ensures that every production deployment changes `sw.js` byte-for-byte and provides a lightweight HTTP seam to check build provenance without downloading heavy assets.

### Deliverables
1. **Dependencies (`package.json`)**:
   - Install `vite-plugin-pwa` in `devDependencies`.
   - Install `workbox-window` in `dependencies`.
2. **Build Configuration (`vite.config.ts`)**:
   - Configure `VitePWA` with `generateSW` and `registerType: 'prompt'`.
   - Setup precache glob patterns (`**/*.{js,css,html,svg,png,webmanifest}`).
   - Define compile-time `__APP_BUILD_INFO__` containing `{ version, buildId, timestamp, commit }`.
   - Implement Vite build plugin to emit `dist/version.json` with the exact build metadata.
3. **Type Declarations (`src/types/telemetry.ts` & `src/vite-env.d.ts`)**:
   - Define `AppBuildInfo` interface.
   - Declare global `__APP_BUILD_INFO__` for TypeScript compiler.

### Verification
- Run `npm run build` to verify:
  - TypeScript compiles with zero errors.
  - `dist/sw.js` is generated by Workbox with dynamic precache hashes.
  - `dist/version.json` is generated and contains valid JSON with `version`, `buildId`, `timestamp`, and `commit`.
