# 0002 Adaptive Remediation and Friendly Deconstruction

We decided that in Weak-Spot Drill, incorrect responses do not advance the queue with a penalty boop. Instead, they present a "Friendly Deconstruction" modal decomposing the problem into distributive anchor facts (e.g. splitting through $\times 5$ or doubling) and re-queue the fact for a later attempt within the same session. This prioritizes pedagogical memory consolidation over rote quiz grading.
